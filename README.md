# Interaktiver Lebenslauf – Mathias Goerrings

Statische, selbstständige Website (eine einzige `index.html`, kein Build-Prozess,
keine Abhängigkeiten außer einem Google-Fonts-Link). Terminal-/Pixel-Design,
fünf Bereiche (`whoami`, `erfahrung`, `skills`, `ausbildung`, `kontakt`),
zugänglich über eine Willkommensseite mit Foto.

## Dateien

- `index.html` – die komplette Website
- `lebenslauf-mathias-goerrings.pdf` – klassische PDF-Version, verlinkt im
  Kontakt-Bereich der Website zum Download

## Für Claude Code: Aufgabe

Richte für dieses Projekt Versionskontrolle und Hosting über GitHub Pages ein:

1. Git-Repository in diesem Ordner initialisieren (falls noch nicht vorhanden)
   und alle Dateien committen.
2. Ein neues **öffentliches** GitHub-Repository anlegen (Name z. B. `lebenslauf`)
   – per `gh repo create`, falls die GitHub-CLI verfügbar und eingeloggt ist,
   sonst nachfragen, wie das Repo angelegt werden soll.
3. Den `main`-Branch dorthin pushen.
4. GitHub Pages für den `main`-Branch (Root-Verzeichnis `/`) aktivieren –
   entweder per `gh api`/`gh` Befehlen, oder falls das nicht klappt, mir genau
   sagen, welche Einstellung ich manuell unter Settings → Pages vornehmen muss.
5. Am Ende die finale Live-URL nennen (Format:
   `https://<username>.github.io/<repo-name>/`).

Bitte vor jedem Schritt kurz erklären, was du tust, und bei der Repo-Erstellung
nachfragen, falls der Name `lebenslauf` schon vergeben ist oder ich einen
anderen Namen bevorzuge.
